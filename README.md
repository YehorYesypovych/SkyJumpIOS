# SkyJump

Аркадна гра для iOS у стилі Doodle Jump.

## Призначення

Персонаж стрибає по платформах і піднімається все вище. Мета — набрати якомога більшу висоту й не впасти.

## Користувач

Гравець, який хоче коротку казуальну гру на кілька хвилин.

## Основні сценарії

1. Гравець починає гру, персонаж автоматично стрибає з платформи на платформу.
2. Платформи різних типів поводяться по-різному: пружина підкидає вище, ламка ламається, рухома переміщується.
3. Рахунок дорівнює максимальній досягнутій висоті.
4. Якщо персонаж падає нижче екрана, гра закінчується.

## Сутності

- **Player** — персонаж гри.
- **Platform** — платформа, на яку стрибає персонаж.
- **PlatformType** — тип платформи: звичайна, рухома, ламка, з пружиною.
- **GameSession** — ігрова сесія: гравець, платформи й рахунок.

## Запуск

Мінімальна версія iOS **17.0**. Відкрити `SkyJump.xcodeproj`, обрати симулятор iPhone, натиснути Run (⌘R), потім кнопку «Запустити демо-сценарій».

Подробиці про практичну роботу 1 (де в коді які конструкції Swift, як перевірити сценарій) — у [docs/practical-1.md](docs/practical-1.md).
